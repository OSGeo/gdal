.. program:: gdal_crs

================================================================================
``gdal crs``
================================================================================

.. versionadded:: 3.14


.. only:: html

    Commands to manage coordinate reference systems (CRS)

.. Index:: gdal crs

:program:`gdal crs` can perform operations on coordinate reference systems (CRS)
files, depending on the chosen operation. This includes (for now) only retrieving information about a CRS.

Synopsis
--------

.. program-output:: gdal crs --help-doc


Available sub-commands
----------------------

- :ref:`gdal_crs_info`: Get information about a coordinate reference system (CRS)
